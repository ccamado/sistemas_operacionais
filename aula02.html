🎯 O que vamos aprender hoje: Entender o que é uma extensão de arquivo, qual tipo ela representa e qual aplicativo é usado para abri-la. Vamos conhecer os formatos de PDF, áudio, vídeo e imagem mais usados.
📖 Conteúdo
🔤 O que é uma extensão?
É o "sobrenome" do arquivo — aparece depois do ponto no nome. Exemplo: foto.JPG → a extensão é .jpg e indica que é uma imagem. A extensão diz ao sistema operacional qual programa deve abrir aquele arquivo!
🗺️ A regra de ouro: Extensão → Tipo de arquivo → Aplicativo para abrir
Exemplo: .mp4 → Vídeo → VLC Player

PDF

Parece igual em qualquer dispositivo. Ótimo para compartilhar sem perder formatação.

🎵

Áudio

MP3 = menor (comprimido). WAV = maior mas qualidade maior.

🎬

Vídeo

MP4 funciona em quase tudo. MKV guarda legendas dentro do arquivo.

🖼️

Imagem

JPG para fotos (menor tamanho). PNG para logos e fundo transparente.

  • 📌
    JPG vs PNG: JPG perde um pouco de qualidade para reduzir o tamanho. PNG mantém qualidade total e suporta fundo transparente.
  • 📌
    MP3 vs WAV: MP3 comprime o áudio (menor). WAV guarda tudo (maior, mas melhor para edição profissional).
  • 📌
    PDF: Ideal para documentos oficiais — parece igual no celular, tablet e computador, não importa o sistema.

🔤 O que é extensão de arquivo?

É o "sobrenome" do arquivo, após o ponto. Ex: foto.JPG → extensão .jpg = imagem. Ela indica ao SO qual programa deve abrir o arquivo.

📄 PDF (.pdf)

Documento que parece igual em qualquer dispositivo. Abrir com: Adobe Reader, Edge ou Chrome.

🎵 Áudio: MP3 vs WAV

MP3 = comprimido, menor tamanho. WAV = sem compressão, melhor qualidade. Abrir com: VLC, Media Player, Spotify.

🎬 Vídeo: MP4 e MKV

MP4 = compatível com tudo. MKV = alta qualidade, suporta legendas embutidas. Abrir com: VLC Player.

🖼️ Imagens: JPG e PNG

JPG = fotos, menor tamanho (com compressão). PNG = logos e imagens com fundo transparente (sem perdas). GIF = imagem animada.
